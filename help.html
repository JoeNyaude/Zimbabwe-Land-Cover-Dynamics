Run a change analysis

  1. Open Change Analysis and draw a rectangle around an area in Zimbabwe.
  2. Select an earlier year and a later year.
  3. Choose Prepare analysis and wait for the imagery and models to finish.
  4. Review the local model's snapshot-level land-cover estimates, paired snapshot classes, and change mask on the results page.
  5. Use Land Cover Maps to switch between the available image layers, or Reports to review and download the latest summary.

Understanding the outputs

The local CNN estimates land-cover classes from dated Esri Wayback snapshots. Its training data is separate from these snapshots, so estimates are not independently validated for the selected area. The change U-Net's mask is also a model estimate, not a measured area of verified land-cover change.

Esri Wayback release dates indicate when a release was published. The underlying image at a particular location may have been captured earlier.

Results are model estimates and should be compared with local reference data before drawing conclusions.
